A program that writes the funniest final text a dying phone sends at one percent battery: "Before I die: I cancelled your 7am alarm. Sleep in. Bring a charger next time." — 78 characters, in the phone's own voice, with a real turn (the phone spends its last percent cancelling your alarm) and a dying demand for a charger.

## Run it

```sh
python3 main.py
```
